Simple Hacktoberfest Attending Poster — mobile-ready

Run:
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Right-click index.html → Open with Live Server.
4. Upload photo, type name, adjust zoom.
5. Drag the photo within the circular frame using mouse or finger.
6. Click Download to save the PNG.

The photo is clipped to the circle and its movement is constrained so it cannot slide out and reveal empty gaps. Touch pointer events are supported for mobile browsers. Keep poster-template.png in the same folder as index.html.

Note: the supplied artwork is used as the background. Logos/event text are baked into the image. The illustration includes a stylized Hyderabad skyline; to make Charminar architecturally more accurate, replace poster-template.png with a verified, licensed Charminar illustration/background while keeping the same dimensions.
